01 / Data model

One ownership rule per kind of data.

ZyenLang keeps value semantics and identity semantics separate, so function signatures say what they mean.

V

Structs are values

Pass a struct to copy it. Use &Struct for a readonly borrow and &mut Struct to update the caller.

I

Classes have identity

A class value is already an ARC handle. Pass it directly; wrapping it in another reference is a compile error.

C

Native stays close

The C11 backend and typed ABI v3 let adapters expose handles, slices, callbacks, enums, flags, and errors.

02 / Language

A small surface with real structure.

struct Point {
    x: i32
    y: i32
}

fn replace(point: &mut Point) void {
    REF_SET__(point, Point{x: 20, y: 22})
}
Value by default.Borrow only when the function needs the caller's storage.
class Player {
    health: i32 = 100

    init(health: i32) {
        this.health = health
    }

    public mut fn damage(amount: i32) void {
        this.health -= amount
    }
}
Shared identity.Passing Player retains the same ARC-managed instance.
import std::c_module as c

native module graphics = c::load("native/graphics.zlcm.h")

fn main() i32 {
    let window = graphics::open("Demo", 800, 480) catch err {
        return 1
    }
    return 0
}

03 / Quickstart

From clone to native executable.

The current public alpha installs from source and uses the compiler available on your machine.

  1. 1

    Install

    Clone the repository and install the CLI in editable mode.

    python -m pip install -e .
  2. 2

    Create

    Generate a project with a manifest and source tree.

    zy new hello
  3. 3

    Run

    Check, compile, link, and launch the default target.

    cd hello && zy run

Windows PowerShell users can run the final commands on separate lines. Binary releases are planned after platform packaging is independently verified.

05 / Status

Built in public, still experimental.

ZyenLang can build native programs today, but syntax compatibility and Rust-equivalent safety are not promised yet. The useful feedback now is concrete: installation failures, unclear diagnostics, and programs the language cannot express.
